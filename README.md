# MSc_Statistics
Repository containing coursework material for the MSc Statistics at Imperial College London.

The Term 1 courses are:
* Computational Statistics and Machine Learning
* Fundamentals of Statistical Inference
* Probability for Statistics
* Data Science

More info can be found in the [MSc Statistics](https://www.imperial.ac.uk/mathematics/postgraduate/msc/statistics/) webpage.
